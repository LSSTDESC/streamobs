streamobs.background.storage module#

Persistence layer for precomputed background CMD histogram grids.

class streamobs.background.storage.BackgroundStorage(base_path=None, survey_name='lsst', **kwargs)[source]#

Bases: object

Save and load precomputed color–magnitude diagram (CMD) histogram grids.

One compressed parquet file per (source_type, bands) combination, e.g. stars_gr.parquet. Inside that file there is one row per (maglim_b2, maglim_b1) grid point, where b1 = bands[0] (color band) and b2 = bands[1] (reference/magnitude band).

CMD counts are stored as density (counts per deg²). Multiply by the target pixel area to obtain expected object counts.

File format — one row per (maglim_b2, maglim_b1) pair:

maglim_b2 | maglim_b1
| color_edge_min | color_edge_max | n_color
| mag_edge_min   | mag_edge_max   | n_mag
| counts  (list of n_color × n_mag floats per deg², row-major)

Bin edges are derived from (edge_min, edge_max, n_bins) on load. Bin centers are not stored; compute them from edges when needed.

When reading for a specific (maglim_b2, maglim_b1) pair, pyarrow predicate pushdown is used so that only the relevant row groups are read from disk — the full file is never loaded into memory.

Parameters:

  • base_path (str, optional) – Root directory for resource files. Defaults to {package_root}/data/background/.

  • survey_name (str, optional) – Survey identifier (e.g. 'lsst'). Used in the file path.

Examples

>>> storage = BackgroundStorage(survey_name='lsst')
>>> path = storage.get_path('stars', ('g', 'r'))
>>> # -> .../data/background/lsst/stars_gr.parquet
